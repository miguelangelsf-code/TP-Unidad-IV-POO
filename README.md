## Cómo ejecutar los ejercicios

1. Tener instalado **Python 3**.
2. Descargar o clonar este repositorio.
3. Abrir una terminal en la carpeta del proyecto.
4. Ejecutar el archivo deseado, por ejemplo:

```bash
python ejercicio_1.py
```

Para ejecutar otro ejercicio, cambiar el número del archivo. Algunos programas solicitan datos mediante el teclado.

## Conceptos utilizados

- Creación de clases y objetos.
- Definición de atributos y métodos.
- Constructores mediante `__init__`.
- Representación de objetos con `__str__`.
- Manejo de listas y relaciones entre objetos.
- Cálculos, condiciones e interacción por consola.
